# Octane Nexus — Full Context

**Last updated:** February 12, 2026

---

## Project Overview

Octane Nexus is a Next.js 14 creator terminal: a "calm engine for social growth" with a full content pipeline from idea to posted content, AI-powered tools, brand identity, and social monitoring.

**Core pipeline:** Idea → Scripting → Filming → Ready → Scheduled → Posted

**Product pillars:** Identity Sniper (Authority Architect), Algorithm Lab (blueprints), Active Librarian (saved content + playbooks).

---

## Tech Stack

- **Framework:** Next.js 14 (App Router), TypeScript
- **Styling:** Tailwind CSS (dark theme: slate-950, amber-500 accent, emerald success)
- **Auth & DB:** Supabase (auth, PostgreSQL, storage)
- **Payments:** Stripe (checkout, webhooks)
- **AI:** Google Gemini (`@google/generative-ai` via `@/lib/gemini`), OpenAI (DALL-E via `@/lib/image-gen`)
- **Media:** fluent-ffmpeg (overlay burn-in), sharp (image rendering), Pexels (stock video)
- **Charts:** Recharts
- **Toasts:** Sonner (`@/components/Toaster`)
- **Icons:** Lucide React
- **Testing:** Playwright (smoke, explorer, mvp-loop)

## Key Flows

### Content pipeline (Production → Schedule → Posted)
1. Ideas from Dashboard/IdeaLab or Trends.
2. Script in ScriptEditorModal (Hook/Meat/CTA) → Generate Assets → status READY.
3. READY card → "Schedule" (data-testid schedule-post-btn) → ScheduleModal (date/time/platform). Validation: "Please pick a date" if no date (schedule-post.ts).
4. Scheduled posts on Schedule page calendar.
5. Click scheduled item → detail modal (data-testid schedule-detail-modal) → "Mark as Posted" (data-testid mark-posted-btn).
6. **Mark as Posted** (schedule/page.tsx): updates content_posts.status = 'posted'; inserts instagram_posts row (posted_at = now); updates **profiles**: streak_count, last_post_date, xp += 25; dispatches **creator-daily-refresh** so CreatorDailyBar refetches.
7. Intelligence context and Nexus Chat use instagram_posts / profiles.

### Streak & XP (Mark as Posted)
- **Timezone-safe:** Uses `toDateString()` for "today" vs "yesterday" (local date).
- **Streak:** If last_post_date is today → streak unchanged. If last_post_date was yesterday → streak += 1. Else → streak = 1. First post ever → streak = 1.
- **XP:** +25 per post. Toast: "Posted! Streak: Nd 🔥 +25 XP".

### Creator Daily Bar
- **Mount:** Dashboard layout; fetches GET /api/creator/today on load.
- **Refresh:** Listens for `window` event **creator-daily-refresh** (fired after Mark as Posted) and refetches.
- **Payload (CreatorTodayPayload):** ideasCount, scriptingCount, readyCount, scheduledCount, lastPostAt, streakCount, xp, hasPostedToday, nextBestAction.
- **nextBestAction priority:** If hasPostedToday → review_performance; else if readyCount > 0 → film; else if scriptingCount > 0 → finish_script; else if ideasCount > 0 → turn_idea_into_script; else grab_trend.
- **Actions (ACTION_MAP):** review_performance → Monitoring; film → Post Lab; finish_script / turn_idea_into_script → Production; grab_trend → Trends. Each has label, guidance, href, chatPrompt, Icon.
- **UI:** Pipeline count chips (Ideas, Scripting, Ready, Scheduled), streak chip, XP chip (violet), primary CTA, "Ask Nexus" link to /dashboard/chat?prompt=...

### Identity Sniper (Authority Architect)
- Multi-step: Platform → Purpose → Setup → Handle Sniper → Bio → Description → Profile Pic → Banner → Brand Identity. Saves to profiles.

### Demo mode (NEXT_PUBLIC_DEMO_MODE=true)
- Settings → Demo tab: "Load Demo Data" / "Reset Demo Data".
- **POST /api/demo/seed:** Idempotent: deletes existing [DEMO] content_posts/saved_blueprints and tracked demo_seeded_ids rows, then inserts content_posts (titles [DEMO]…), saved_blueprints ([DEMO] idea), profile_analytics_history (tracked), instagram_posts (tracked), linked_accounts @demo_user. Uses lib/demo-seed (Mulberry32 seed 42).
- **POST /api/demo/reset:** Deletes [DEMO] content_posts/saved_blueprints; deletes by demo_seeded_ids for profile_analytics_history and instagram_posts; clears demo_seeded_ids; removes linked_accounts.instagram if @demo_user.
- DemoNudge on empty Dashboard, Production, Post Lab, Monitoring, Library.

### Render (finalizeVideoById)
- Fetch post (FILMING); pick background (pickBackgroundForPost or existing); render overlay (renderQuoteCardImage) → upload; ffmpeg burn or raw MP4 upload; update post READY, final_video_url, overlay_image_url.

### Intelligence context (GET /api/intelligence/context)
- Profile niche/brand_vision; instagram_posts (quality_score, posted_at); buildNexusIntelligence → bestFormat, bestPostingHours, strongestPlatform, strategicFlags. Used by Nexus Chat. Dynamic (cookies).
